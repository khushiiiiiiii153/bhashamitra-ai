## 🚀 About BhashaMitra AI

**BhashaMitra AI** is a next-generation, open-source multilingual AI platform built for regional inclusivity. Whether you want to learn programming, explore science and technology, or ask general queries, BhashaMitra AI answers complex questions in your preferred regional language with a lightning-fast response engine.

---

## ✨ Key Features

- **🌐 Multilingual Support:** Native interaction in Hindi (`hi-IN`), Marathi (`mr-IN`), and English (`en-IN`).
- **🧠 Universal Knowledge Engine:** Capable of answering questions across Coding, AI/ML, IoT, Cloud Computing, and Science.
- **⚡ High-Performance Backend:** Powered by FastAPI with robust asynchronous processing and smart fallback capabilities.
- **🎨 Modern Dark-Themed UI:** Clean, responsive, and mobile-friendly interface built with Tailwind CSS and FontAwesome icons.
- **🔌 Flexible AI Integration:** Easily compatible with Groq, OpenAI, or Sarvam AI APIs.
